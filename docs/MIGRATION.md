# خطة الترحيل الداخلية

- الواجهة: HTML/CSS/JavaScript خفيفة بتصميم Dashboard، بطاقات، مؤشرات، شريط جانبي وإعدادات منظمة.
- الغلاف: Tauri 2 مع نافذة Windows أصلية وinstaller.
- التوافق: المصدر الأصلي محفوظ في `legacy/`، ويتم بناؤه كـ sidecar عبر PyInstaller.
- البيانات: قراءة وحفظ JSON من مجلد بيانات التطبيق، مع الحفاظ على حقول السيرفرات ومسارات M3U وحقول المعالجة.
- الأمان: `config.json` الحقيقي لا يدخل Git، وملف المثال فقط هو المتعقّب.
