# SFTP Studio — UI Kit Reference

مرجع تصميم خفيف خاص بالأداة فقط، بديل عن ملف Figma الكامل.

## Visual direction

Dashboard نظيف مستوحى من لوحات التحكم الحديثة: خلفية رمادية فاتحة، بطاقات بيضاء، شريط جانبي هادئ، ألوان حالة واضحة، ومساحات واسعة حول المعلومات.

## Design tokens

- Background: `#F7F8FC`
- Surface: `#FFFFFF`
- Primary: `#5267F5`
- Cyan accent: `#26B9D2`
- Success: `#39B98A`
- Warning: `#F5A54A`
- Danger: `#E66C75`
- Text: `#182230`
- Muted text: `#7B8798`
- Border: `#E9EDF4`
- Radius: 10px controls, 16px cards, 20px hero
- Font: Segoe UI / Tahoma / Arial

## Components used

1. Sidebar navigation with active state and numeric badge.
2. Server status pill.
3. Gradient hero banner with primary action.
4. Metric cards with progress/spark indicators.
5. Activity list.
6. Progress bars for M3U/VOD paths.
7. Server connection form.
8. M3U path cards.
9. FFmpeg settings form and toggle.
10. Firefox bridge / SSH tunnel status cards.
11. JSON compatibility settings panel.

## Prototype scope

هذه المكوّنات هي الأساس الذي سيتم تطبيقه في الواجهة النهائية. لا يتم تضمين أي صفحات أو صور أو مكوّنات إضافية من Dashboard UI Kit العام.
